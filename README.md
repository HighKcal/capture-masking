# 가림캡처

팀 저장소용 신규 초안 · 최초 반영일에 기존 README가 있으면 필요한 단락을 합친다.

가림캡처는 Windows의 주 모니터에서 선택한 영역이나 로컬 PNG를 받아 개인정보 후보를 표시하고, 선택된 영역의 픽셀을 가려 미리보기와 클립보드에 제공한다. 탐지 대상에는 이름·전화번호·이메일이 있고 RC1은 계정 후보도 처리한다.

## 작업 위치

개발 앱 진입점은 `experiments/gui-selection-v0/app.py`다. 영역 캡처는 팀원 1, 픽셀 마스킹은 팀원 2, GUI·클립보드는 팀원 3, 분석·통합·배포는 통합 담당자가 맡는다. 기존 소스와 시험을 날짜별로 이관하고 새로 수행한 변경·시험은 해당 날짜에 기록한다.

## 개발 및 실행 환경

RC1 유지보수 기록의 환경은 Windows x64, CPython 3.12.10이며 GUI·OCR·이름 모델은 각각의 Python 환경을 사용한다. 의존 패키지와 빌드 입력은 12/03에 이관하는 `distribution/rc1/README.md`와 `runtime/RUNTIME_MANIFEST.json`(같은 폴더 아래)을 참조한다. 실행판을 받은 팀원은 12/04의 `distribution/rc1/빠른 시작.txt`를 따른다. 소스 인계에는 모델·실행 파일이 없고 개인 경로가 있는 명세와 권리 미확인 SVG는 보류했다.

GUI-CHECK01 개발 수정본에서는 같은 후보를 해제하고 다시 선택하면 체크 표시·선택 수·미리보기 가림이 함께 복원된다. Windows 검증과 독립 검토가 끝난 기준이며, 팀원 PC 결과는 실제로 수행한 뒤 기록한다. 기존 RC1 실행판에는 수정 전 체크 표시가 남아 있다. 수정 동작은 개발본에서 확인한다. 개발본의 flow_view.py는 원래 RC1 잠금과 달라 해당 파일의 빌드 해시 검사가 실패한다.
